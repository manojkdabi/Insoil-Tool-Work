About These Mockups

This collection presents a comprehensive UI theme standardization for the Insoil Tool. Each mockup demonstrates how a unified design system creates a professional, cohesive, and engaging user experience across all modules.

All mockups are interactive HTML files that showcase the proposed color palette, component designs, spacing system, and visual hierarchy. They can be viewed in any modern web browser without requiring a build process.
